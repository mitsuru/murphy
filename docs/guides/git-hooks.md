# Git hooks (`murphy install --git-hook`)

B8 (murphy-fmw.2.8). Scaffolds a working pre-commit hook for one of three
frameworks. Phase 9 gate 7: `murphy install --git-hook` can emit a scaffold
for any of the pre-commit / lefthook / overcommit configurations.

## Usage

```console
$ murphy install --git-hook
Generated lefthook.yml (activate with `lefthook install`)

$ murphy install --git-hook --tool pre-commit
Generated .pre-commit-config.yaml (activate with `pre-commit install`)

$ murphy install --git-hook --tool overcommit
Generated .overcommit.yml (activate with `overcommit --install`)

$ murphy install --git-hook --tool all
Generated lefthook.yml (activate with `lefthook install`)
Generated .pre-commit-config.yaml (activate with `pre-commit install`)
Generated .overcommit.yml (activate with `overcommit --install`)
```

- Default `--tool` is `lefthook` (single static binary, fastest setup).
- Existing files are never overwritten unless `--force` is passed:
  `murphy install --git-hook --tool all --force`.
- Without `--git-hook` the command exits 2 (nothing to install).
- `--tool all` is atomic: if any target exists and `--force` is absent,
  nothing is written.

## Scaffolds

### lefthook (`lefthook.yml`)

```yaml
# Generated by `murphy install --git-hook --tool lefthook`.
# Requires lefthook: https://github.com/evilmartians/lefthook
# Activate with: lefthook install
pre-commit:
  parallel: true
  commands:
    murphy:
      glob: "*.rb"
      run: murphy lint --format progress {staged_files}
```

Activate:

```bash
lefthook install
git commit   # runs murphy on staged *.rb files
```

### pre-commit framework (`.pre-commit-config.yaml`)

```yaml
# Generated by `murphy install --git-hook --tool pre-commit`.
# Requires pre-commit: https://pre-commit.com/#installation
# Activate with: pre-commit install
repos:
  - repo: local
    hooks:
      - id: murphy
        name: murphy lint
        entry: murphy lint --format progress
        language: system
        types: [ruby]
        pass_filenames: true
```

Activate:

```bash
pre-commit install
git commit   # runs murphy via the local system hook
```

### overcommit (`.overcommit.yml`)

```yaml
# Generated by `murphy install --git-hook --tool overcommit`.
# Requires overcommit: https://github.com/sds/overcommit
# Activate with: overcommit --install && overcommit --sign
PreCommit:
  Murphy:
    enabled: true
    description: Run murphy lint on staged Ruby files
    required_executable: murphy
    command: ['murphy', 'lint', '--format', 'progress']
    include: '**/*.rb'
```

Activate:

```bash
overcommit --install
overcommit --sign   # trust the new config
git commit
```

## Notes

- Hooks run `murphy lint --format progress` (human one-line progress,
  exit 1 on offenses to block the commit). Use `--format json` in CI
  instead; see `docs/guides/output-formats.md`.
- The `murphy` binary must be on `PATH` for the hook to run
  (`cargo install` or `cargo build --release` + `PATH` export).
- CLI-only scaffolding: no `MURPHY_PLUGIN_ABI_VERSION` change, no config
  migration. Re-running with `--force` restores the stock templates.
